# Data Dictionary

| Column | Description |
|---|---|
| customer_id | Synthetic unique customer identifier |
| age | Customer age in years |
| gender | Synthetic gender category |
| state / city | Indian state and city assigned to the synthetic record |
| nationality | Indian or NRI category |
| employment_type | Employment category |
| account_type | Savings, Current, Salary or Premium |
| branch_code / branch_name | Synthetic branch identifier and label |
| customer_since_year | Synthetic account relationship start year |
| annual_income_inr | Estimated annual income, INR |
| income_band | Project-defined Low / Mid / High segment |
| bank_deposits_inr | Total bank deposit portfolio value, INR |
| savings_account_balance_inr | Savings balance, INR |
| checking_account_balance_inr | Checking/current balance, INR |
| fixed_deposits_inr | Fixed deposit value, INR |
| recurring_deposits_inr | Recurring deposit value, INR |
| foreign_currency_balance_inr | Foreign-currency account value converted/stored as INR demonstration amount |
| bank_loans_inr | Total loan amount, INR |
| home_loan_inr / personal_loan_inr / vehicle_loan_inr | Loan product amounts, INR |
| credit_card | Whether a credit card is assigned |
| credit_limit_inr | Credit limit, INR |
| credit_card_balance_inr | Outstanding credit card balance, INR |
| superannuation_savings_inr | Long-term retirement savings proxy, INR |

All rows and financial amounts are generated synthetic values for demonstration. The dataset is not a representation of any bank's portfolio.
